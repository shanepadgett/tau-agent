# Agents

- Plans live in `docs/plan/`. When the user says they want to consider something, record it in the right plan file (features, architecture, spikes, or Open in `README.md`) in the same reply.
- Keep plan files short and plain. No sprawling docs.
- Spikes go in `spikes/<name>/` with a `NOTES.md`.
- Do not commit; the user commits.
