# Live checks

Status: collecting, 2026-10-13. Run these with real models when the TUI exists; a failure becomes a fix then, not a blocker now.

Each check names what it covers, how to run it, and what passes. Remove a check when it passes; a failure moves to the plan of the fix.

| Built in | Check | How | Passes when |
| --- | --- | --- | --- |
| Slice 4c | Script edits and the write queue in daily use | real tasks in a project, on Claude and a ChatGPT plan route | failed scripts are fixed with small edits, not sent again whole; two edits to one file in a script both land |
| Instruction files and skills | `always: true` and `read-when` files, skills from each folder | a project with `.tau/instructions/` and `.agents/skills/`; ask for a task that needs one of each | `always` text is in the system prompt; the model reads the `read-when` file and calls the skill when the task matches |
| Slice 4d | Fixers | `.tau/checks.json` with a real formatter in `fix`; ask for an edit with bad formatting | the file ends up formatted; the model never sees the formatter's output |
| Slice 4d | The `checks` tool | a real lint or type check in `check`; ask for a change | the model calls `checks` before its final message, and fixes a failure it reports |
| Slice 4d | Checks at the end of a run | a change that breaks a check, and a model that ends its turn without calling `checks` | Tau runs the checks, the model gets the failure and fixes it, and the run ends `answered`; after 3 failed tries the run ends `checks-failed` |
| Slice 4d | Changes through `sh` | ask the model to change a file with a shell command, such as `sed -i` | the fixers and checks run on that file |
| Slice 4d | Repeat limit | the live model matrix (`bun spikes/live-models/check.ts`) | no model hits `repeated-call` on a task it can do; a model stuck on one failing call ends the run within 3 calls |
| Slice 4e | Shell output files and timeouts | ask for a long command result, a search for a line omitted from its preview, and a noisy command with a short timeout | the model searches the linked full log; timeout includes a usable preview and log path |
| Slice 4e | Script output files | ask for a result over 50 KB, then one past the interpreter's 10 MB returned-output limit | the model uses the saved file, reduces what it prints, and does not claim discarded script output is recoverable |
| Slice 4e | Combined check reports | several noisy failed checks, each under 50 KB, with a combined report over the cap | the model reads the combined-report file and command logs, fixes the failures, and reaches passing checks |
| Reload | Restart into changed code | run `bun src/cli/main.ts` in this repository, type a prompt without sending it, change a file in `src/` from another editor; then break a file, then fix it | the chat restarts within about a second with the same session and the unsent prompt; a broken file leaves the chat running and shows the first line of the reason in the status strip above the input, with the full reason in `~/.tau/logs`; the fix clears the line and restarts the chat |
| Daily driver | Markdown, `/model`, steering, footer, `/sessions` | in a chat, ask for an answer with a heading, a list and a Python block; `/model` and pick another model; during a long run press Enter on a steering message and Tab on a queued one; then `/sessions` and pick an older session, and `/new` | the Markdown is styled and the Python block colored (after a first download); the next reply comes from the picked model; the model answers the steering message in the same run and the queued prompt runs after it; the footer shows context and cost that match the provider's usage page; the picked session opens with its history |
| Slash commands | The command list in a real terminal | type `/`, then `/se`, move with the arrows, press Tab; during a run type `/re` and press Escape | the list shows the matching commands and the chosen one; Tab puts the command in the input without sending it; Escape closes the list and the run goes on |
| Daily driver | Skipped skills in the status strip | add `.agents/skills/x/SKILL.md` with no description and send a prompt; then add a description and send another | the strip shows the skipped skill after the first prompt and drops it after the second |
| Diagnostics | Log files, failed runs, copy on select | in a chat, select text with the mouse and paste it elsewhere; make a run fail (such as a wrong API key), then send "try again"; then `rg -l <session-id> ~/.tau/logs` | the pasted text matches the selection; the failed run shows after a resume and the model knows the last run failed; `rg` finds the run's error with its cause |
| Model favorites | `/model` with Ctrl+F in a real chat | log in to two providers; open `/model`, press Ctrl+F on two models, filter, close and open a new chat | the two models list above the line in provider, maker, model order; a long name ends in `…` and its provider still shows; a new chat lists them first; `~/.tau/favorites.json` holds them |
| `/commit` | Checks, plan, commits and push in a real repository | in a scratch repository with an upstream and changes in code, tests and docs: run `/commit`, then `/commit make this one commit`; make a check fail once; answer the push question both ways | failed checks commit nothing and reach the model; the plan groups code with its tests; Enter commits each group with only its files; the push goes to the upstream |
| Web | `tools.web.search` and `tools.web.fetch` in real chats | ask `Find the current Bun release notes and list the breaking changes` on Anthropic (Claude plan), Codex and OpenCode Go; on OpenCode Go once without and once with `EXA_API_KEY` | Claude and Codex return `route` `anthropic` and `openai` with sources; OpenCode Go returns `route` `exa` with a key, and without one either works or fails with the `EXA_API_KEY` message; the model fetches a source and answers from it |
| References | `/references` in a real terminal | run `/references`, Ctrl+N with a real GitHub URL, attach it, then ask the model to read a file from it; try Ctrl+R, Ctrl+U, Ctrl+O and Ctrl+X | the clone row shows `↓ N%` then the branch; the sidebar lists the attached name; the model finds the repo under `~/.tau/references`; branch switch, update, open and delete work |
| Thinking levels | Shift+Tab and each protocol's request in real chats | on Anthropic (Sonnet 5.5), Codex (GPT-6 Luna) and OpenCode Go (DeepSeek V4.1 Flash): step with Shift+Tab, send a prompt at `off` where offered and at `max`, then `/model` to a model without the level, and resume the session | each call succeeds and thinks more at `max`; the footer shows the nearest offered level after `/model`; the resumed chat shows the saved level |
| `/qna` | The panel and the question tool with real models | in a chat, have the model ask you something, then run `/qna`; answer a select, a confirm and an input question, add a note with `n`, type an `Other…` answer, add context, send; then press Escape in a second panel; on Anthropic, Codex and OpenCode Go | the model calls `ask_question` and the run ends; the panel shows every state; the answers arrive as one message and the model continues from them (a missing tool definition in the history causes no provider error); Escape sends nothing |
