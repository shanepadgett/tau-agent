# Remove Explore and Review

Remove the Explore extension (12 structural tools, read-outline hook, AST engine) and the Review extension completely. Cut file injection down to full-file reads, the only mode handoff uses.

## Decisions

- Explore: delete the extension, `src/ast`, its grammars, dependencies, CI, tooling, dev widgets, docs, and all its tests.
- Review: delete the extension and `shared/isolated-session.ts` (review is its only user).
- File injection: full-file reads only. Drop `outline`, `auto`, `show`, and line ranges. Keep the public `prepareFileInjection` export.
- `tau:file-mutation.applied`: remove. Explore was its only listener.
- Pi minimum: unchanged.

## Architecture

```text
before                                          after
explore ──registers──> tau.file renderer        handoff ──registers──> tau.file renderer
explore ──answers────> tau:file-injection.prepare        └──calls────> prepareFileInjection(request)
handoff ──emits event─> prepareFileInjection(pi, req)                    (reads files directly)
patch   ──emits──────> tau:file-mutation.applied ─> explore     patch: no event
review  ──spawns subagent with explore loaded                   (gone)
```

No system is added. File injection becomes a plain module: no host, no event round-trip.

## File injection (`packages/agent/src/file-injection/index.ts`)

```ts
export interface FileInjectionRequest {
 cwd: string;
 source: string;
 batchId: string;
 paths: ReadonlyArray<string>; // replaces files[] with mode/ranges/name/view
}

export interface FileInjectionDetails {
 v: 1;
 rowId: string;
 path: string;
 cwd: string;
 source: string;
 batchId: string;
 status: "injected" | "failed";
 error?: string;
 readCache?: ReadCacheMetaV1;
}

// no pi argument, no event
export async function prepareFileInjection(request: FileInjectionRequest): Promise<PreparedFileInjection[]>;

// renamed from registerFileInjection; renderer only
export function registerFileInjectionRenderer(pi: ExtensionAPI, rowState: ToolRowStateStore): void;
```

- Per path: strip a leading `@` inline, then `prepareFull`. Failures become `status: "failed"` rows as today.
- Delete: `FileInjectionMode`, `FileInjectionFile`, `FileInjectionHost`, `requireHost`, `injectionKind`, `prepareShow`, `prepareRangedRead`, `outlineFile`, `prepareOutline`, `prepareLargeSourceOutline`, `isShowView`, `normalizeLineRanges`, `parseRanges`, the `kind`/`ranges`/`showName`/`showView` fields, `OUTLINE_OPTIONS`, and every `../ast/*` import.
- Renderer label is always `read`. Old `outline`/`show` rows in existing sessions render as `read`.
- `signal` is dropped (handoff never passes one).
- Full-mode error text drops "outline or read a range instead".

Call sites:

- `extensions/handoff/index.ts`: create `createToolRowStateStore(pi, "handoff.tool-row-state")`, call `registerFileInjectionRenderer(pi, rowState)`, and call `prepareFileInjection({ cwd, source: "handoff", batchId, paths: draft.files })`.
- `shared/events.ts`: remove `tau:file-injection.prepare`, `tau:file-mutation.applied`, and the file-injection type import.
- `extensions/patch/index.ts`: remove the `emitTauEvent(...)` block. Keep the `tool_result` error flagging. Patch's `resultingFingerprint` and `snapshotRanges` stay (patch details and an existing patch test use them).

## Cache impact

Removing 12 tools and the Explore guidance changes the tool list and system prompt once, after `/reload`. Later requests are stable again. No request field becomes mutable.

## Out of scope

- `readCache` (from `shared/full-file-knowledge.ts`) is written into `tau.file` details, but nothing in the repo reads it. It is unrelated to Explore and stays.
