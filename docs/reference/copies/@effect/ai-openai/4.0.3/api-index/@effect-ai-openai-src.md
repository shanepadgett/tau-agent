# @effect/ai-openai/src

- `Generated`
- `OpenAiClient`: The `OpenAiClient` module defines the low-level Effect service used by the OpenAI integration for Responses API and embedding requests.
- `OpenAiClientGenerated`
- `OpenAiConfig`: The `OpenAiConfig` module lets a workflow temporarily customize the HTTP client used by `@effect/ai-openai` request helpers.
- `OpenAiEmbeddingModel`: The `OpenAiEmbeddingModel` module provides the OpenAI implementation of Effect AI's `EmbeddingModel` service.
- `OpenAiError`: OpenAI error metadata augmentation.
- `OpenAiLanguageModel`: The `OpenAiLanguageModel` module provides the OpenAI Responses API implementation of Effect AI's `LanguageModel` service.
- `OpenAiSchema`: The `OpenAiSchema` module defines the request, response, streaming, and embedding schemas used by the handwritten OpenAI client.
- `OpenAiTelemetry`: The `OpenAiTelemetry` module defines OpenAI-specific telemetry attributes and a helper for adding them to a tracing span.
- `OpenAiTool`: The `OpenAiTool` module defines OpenAI provider tools for Effect AI language model requests.
